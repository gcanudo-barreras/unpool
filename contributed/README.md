# Contributed verdicts

Verified by other people, cited, **not re-verified here**. Kept apart from
`fixtures/ground_truth.csv` on purpose: a figure over contributed verdicts is a
real figure and a different one from a figure over verdicts this project
checked, and pooling them would hide which is which (`docs/PROTOCOL.md`,
rule 8).

One file per batch: `<handle>/<tag>.csv`, with the worklist's
`verdict_human` and `notes` columns filled in. See `../CONTRIBUTING.md`.

So far only the author's own batches are here (`gcanudo-barreras/`). The first
batch from anyone else will be the tool's first figure that its author did not
produce; the most useful is a second, blind rating of V25
(`../CONTRIBUTING.md`, section 0).
